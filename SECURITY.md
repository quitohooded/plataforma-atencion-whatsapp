# Política de seguridad

## Cómo reportar una vulnerabilidad

No abras un issue público. Escribí a los autores del proyecto con:

- descripción del problema y su impacto;
- pasos para reproducirlo;
- versión o commit afectado.

Se responde dentro de las 72 horas y, una vez corregido, se publica una versión con el detalle en el
`CHANGELOG.md`.

## Alcance

- Panel web del comercio y sus formularios.
- Webhook de WhatsApp y simulador.
- Manejo de datos personales de compradores y comercios.

## Medidas vigentes

Las medidas de seguridad del producto y el modelo de amenazas del bot se describen en `docs/seguridad.md`.
